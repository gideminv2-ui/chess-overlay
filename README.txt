ШАХМАТЫ ПРОТИВ STOCKFISH — плавающее окно поверх других приложений (Android 8.0+)

КАК СОБРАТЬ ПРИЛОЖЕНИЕ (один раз)
1. Установите Android Studio: https://developer.android.com/studio
2. File -> Open -> выберите папку ChessOverlay. Дождитесь Gradle Sync (нужен интернет).
3. Соберите APK: Build -> Build Bundle(s) / APK(s) -> Build APK(s).
   Файл: app/build/outputs/apk/debug/app-debug.apk
   (или подключите телефон по USB с включённой отладкой и нажмите Run).
4. Скопируйте app-debug.apk на телефон и установите (разрешите установку из этого источника).

ПЕРВЫЙ ЗАПУСК
- Откройте «Шахматы Stockfish». Android попросит разрешение «Поверх других приложений» — включите.
- Откройте приложение ещё раз: появится плавающее окно. Выберите цвет и играйте.
- Заголовок окна: перетаскивание. Кнопки: ⤢ размер, — свернуть в кружок (тап по кружку разворачивает), ✕ закрыть.
- Кнопки ↶ откатывают 1, 3 или 5 полных ходов.

ИНТЕРНЕТ
Движок Stockfish (stockfish.js 10.0.2) и chess.js подгружаются с cdnjs при первом запуске.
Для работы без интернета положите файлы stockfish.js и chess.min.js в app/src/main/assets/
и пересоберите приложение: они подхватятся автоматически.
